# 纪律锁：用代码约束情绪化交易

## 问题

人会在亏损后想翻本、在盈利后想加码、在无聊时想"玩一把"。
这些行为通常集中在**高波动的小市值币种**上——它们流动性差、波动大、最容易让人上头。

## 设计

一个每 2 分钟运行一次的守护进程，规则极简：

### 分类（不手写名单）

```
美股 = 交易所官方分类（X 前缀现货）对应的永续合约
正规加密 = BTC / ETH / XRP / SOL
其余任何加密持仓 = 垃圾币
```

**为什么不用手写白名单**：我们手写过一次短名单，结果把用户的一笔
**美股三倍做空 ETF** 当成垃圾币强平了——当时那笔还浮盈。
手写名单永远会漏，必须用交易所的权威分类。

### 动作

1. **立即强平**（市价，reduceOnly，沿用原保证金模式）
2. **钉钉告警**（写明强平了什么、冷静期多久）
3. **冷静期递进**：第 1 次 3 天 → 第 2 次 7 天 → 第 3 次起 14 天
4. **冷静期不可解锁**——这是设计的核心：**上头时求解锁也不解**
5. 7 天无违规自动复位计数

### 安全兜底

- **分类表拉取失败 → 只告警，绝不动手**（宁可漏杀不可错杀）
- 所有强平落台账，可审计
- 每 2 分钟一巡，**动作要快**（不给人上头的时间窗）

## 实际效果

上线前的历史账单显示：用户在一周内因小币种交易净亏 **-181 USDT**，
其中单日净亏 **-260.84 USDT**（65 笔）。

上线后，所有非白名单持仓在 2 分钟内被平掉并锁定冷静期。
